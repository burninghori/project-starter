# 0002. 환경변수 이름은 배포 환경과 같게, 접두어 없이

2026-11-09 · 상태: 확정

## 배경

앱 설정 환경변수에 프로젝트 접두어(`<PREFIX>_DB_URL` 등)를 붙이는 방식도 흔하다. 컨테이너 배포 환경(오케스트레이터의 작업 정의,
비밀 저장소 등)은 보통 `APP_ENV`·`DB_HOST`·`DB_USER`·`DB_PASSWORD` 같은 접두어 없는 이름으로 값을 넣는다.

## 결정

- backend 설정(`backend/app/config.py`)은 **배포 환경이 넣는 이름과 같은 이름**을 접두어 없이 읽는다.
- 배포 환경이 넣지 않는 실행 설정(`APP_HOST`·`APP_PORT`·`APP_RELOAD`·`LOG_LEVEL`)은 컨테이너 이미지(Dockerfile ENV)가 정한다.
- 로컬도 같은 이름을 쓴다(`backend/.env`). DB 접속은 로컬·배포 모두 host/port/name/user/password 다섯 값 한 경로다.
- 코드 짧은 이름(기본 `app`)은 CSS 클래스(`app-`)·로거(`app.*`)·로컬 DB · 버킷 이름에만 쓴다. 환경변수 이름에는 쓰지 않는다.

## 근거

- 배포 환경과 이름이 같으면 매핑 계층이 없어 배포 설정 누락을 부팅 시 바로 잡는다(필수 값에 기본값 없음).
- 접두어가 없으니 서비스 명칭이 바뀌어도 환경변수·배포 설정을 고칠 필요가 없다.

## 영향

- 새 설정을 추가할 때 배포 환경이 주입하는 값이면 배포 설정의 이름을 그대로 쓴다. 배포 설정을 새로 만들 때도 이 이름을 따른다.
